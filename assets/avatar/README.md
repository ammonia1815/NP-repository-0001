# 아바타 이미지

이 폴더에 아래 파일명으로 GIF(또는 PNG/JPG)를 넣으면 앱이 자동으로 사용합니다. 파일이 없는 상태에서는 emoji 기반 임시 아바타가 대신 표시되니, 없어도 앱은 정상 동작합니다.

| 파일명 | 상태 | 언제 표시되나요 |
|---|---|---|
| `idle.gif` | 평소 대기 | 아무 대화도 없을 때 |
| `thinking.gif` | 생각 중 | 사용자가 메시지를 보내고 Claude 응답을 기다리는 동안 |
| `happy.gif` | 기쁨 | Claude 응답의 감정이 happy로 분류될 때 |
| `sad.gif` | 슬픔 | 감정이 sad로 분류될 때 (에러 상황 포함) |
| `surprised.gif` | 놀람 | 감정이 surprised로 분류될 때 |

권장 사항:
- 9:16 세로 비율 (예: 360x640, 540x960) — 아바타 창 자체가 9:16 비율로 만들어져 있어서 이 비율로 만들면 잘리거나 여백 없이 꽉 차게 표시됩니다.
- 배경은 투명 PNG 프레임으로 구성된 GIF를 권장 (투명 창 위에 자연스럽게 올라감)
- 파일 확장자는 반드시 소문자 `.gif`

아바타 위에서 마우스 휠을 돌리면 확대/축소되고, 크기는 다음 실행 시에도 유지됩니다.
